# Every entry that any release of the Linuxfabrik Monitoring Plugins ever placed directly below
# /usr/lib64/nagios/plugins, one name per line, shell globs allowed. Collected from the rpm
# filelists and deb packages on repo.linuxfabrik.ch, the source zips on download.linuxfabrik.ch
# (1.2.0.11 to 8.0.0), every <tree>/<name>/<name> in the history of the monitoring-plugins
# repository, and the artifacts of the compiled installs that predate the packages. Names of the
# distribution's own plugins (check_disk, negate, utils.sh, ...) are deliberately absent: no
# release ever shipped them, and a copy of such a plugin that no package owns is not ours to take.
#
# `monitoring_plugins:remove` deletes each of them unless a package owns it, so the plugins of
# the distribution sharing the directory stay. A source install from this role or the one-line
# installer records what it placed in install-manifest.txt, so this list only has to grow for
# an artifact that neither a package nor a manifest covers.
